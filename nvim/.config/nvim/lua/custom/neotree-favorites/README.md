# Neo-tree Favorites Plugin

Расширение для neo-tree, которое добавляет возможность создавать избранное из файлов и папок.

## Возможности

- ⭐ **Добавление в избранное**: файлы и папки с сохранением иерархии
- 🗑️ **Удаление из избранного**: простое управление списком
- 👁️ **Визуальная индикация**: звездочка рядом с избранными элементами в filesystem view
- 📁 **Отдельный source**: полноценная вкладка "Favorites" в neo-tree
- 💾 **Глобальное хранение**: избранное сохраняется в `~/.local/share/nvim/neotree-favorites.json`

## Использование

### Клавиши

| Клавиша | Действие |
|---------|----------|
| `<leader>E` | Открыть Favorites view (float) |
| `<leader>S` | Добавить текущий файл/папку в избранное |
| `<leader>D` | Удалить текущий файл/папку из избранного |

### Как работает

#### Добавление файла
Когда вы добавляете файл в избранное:
- Добавляется сам файл
- Добавляются все родительские папки (пустые, без содержимого)
- Сохраняется полная иерархия

**Пример:**
```
Добавили: /home/user/project/src/components/Button.tsx

В избранном появится:
📁 src/
└── 📁 components/
    └── 📄 Button.tsx
```

#### Добавление папки
Когда вы добавляете папку:
- Добавляется вся папка рекурсивно
- Добавляются все файлы и подпапки внутри

**Пример:**
```
Добавили: /home/user/project/tests/

В избранном появится всё содержимое tests/ рекурсивно
```

#### Удаление
Удаление работает так же рекурсивно - если удаляете папку, удаляется всё содержимое.

### Визуальная индикация

В обычном filesystem view рядом с избранными файлами и папками отображается ⭐.

### Source Selector

В верхней части neo-tree есть вкладки:
- **Files** - обычный файловый менеджер
- **Buffers** - открытые буферы
- **Git** - измененные файлы
- **⭐ Favorites** - ваше избранное

## Примеры использования

### Сценарий 1: Работа над фичей
Вы работаете над новой фичей, которая затрагивает несколько файлов в разных частях проекта:

1. Откройте neo-tree: `<leader>e`
2. Наведите на нужный файл и нажмите `<leader>S`
3. Повторите для других файлов
4. Откройте Favorites view: `<leader>E`
5. Теперь все нужные файлы в одном месте!

### Сценарий 2: Часто используемые конфиги
Добавьте папки с конфигами в избранное для быстрого доступа:

```
~/.config/nvim/lua/plugins/
~/.config/nvim/lua/custom/
~/.bashrc
~/.tmux.conf
```

## Структура данных

Данные хранятся в JSON формате:

```json
{
  "/home/user/project/src/components/Button.tsx": {
    "type": "file"
  },
  "/home/user/project/src/components/": {
    "type": "directory",
    "recursive": false
  },
  "/home/user/project/tests/": {
    "type": "directory",
    "recursive": true
  }
}
```

## Архитектура

```
neotree-favorites/
├── manager.lua      - управление данными (load, save, add, remove)
├── init.lua         - custom source для neo-tree
├── commands.lua     - команды для neo-tree
└── component.lua    - визуальный компонент ⭐
```

## Troubleshooting

### Не работают горячие клавиши
Убедитесь, что:
1. Neo-tree загружен: `:Lazy`
2. Модули доступны: `:lua print(vim.inspect(require("custom.neotree-favorites.manager")))`

### Не видно индикацию ⭐
Перезагрузите neo-tree: `:Neotree close` → `:Neotree`

### Файл избранного
Расположение: `~/.local/share/nvim/neotree-favorites.json`
Можно редактировать вручную, если нужно.
