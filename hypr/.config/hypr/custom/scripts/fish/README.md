# Fish Configuration Reload - Clipboard Method

## 🎯 Что это?

Этот скрипт копирует команду перезагрузки Fish конфигурации в буфер обмена, чтобы вы могли быстро применить её в нужных терминалах.

## 📋 Как работает

1. Скрипт определяет количество запущенных Fish процессов
2. Копирует команду `source ~/.config/fish/config.fish` в буфер обмена
3. Показывает уведомление с количеством терминалов
4. Вы вставляете команду в нужных терминалах через **Ctrl+Shift+V** и Enter

## 🚀 Использование

Запустите через меню reload:
```bash
bash /home/mr/temp/hypr/custom/scripts/reload/menu-reload.sh
```

Выберите "� Fish Config" и:
1. Получите уведомление о количестве запущенных Fish терминалов
2. Перейдите в каждый терминал с Fish
3. Нажмите **Ctrl+Shift+V** → **Enter**
4. Конфиг перезагружен! ✨

## ⚠️ Почему не автоматически?

**Техническое ограничение Fish shell:**

Fish - это не клиент-серверная архитектура (в отличие от tmux). Каждый экземпляр Fish - это независимый процесс без централизованного управления.

**Попытки автоматизации:**
- ❌ **Сигналы USR1**: Завершают процессы Fish, если обработчик не установлен
- ❌ **Kill -HUP**: Аналогично завершает процессы
- ❌ **Exec в фоне**: Нет доступа к окружению других процессов

**Работающие решения требуют:**
- Модификации исходного кода Fish
- Фоновых процессов-наблюдателей в каждом терминале
- Сложной инфраструктуры с сокетами/файлами

## 🔄 Альтернативные подходы

### Вариант 1: Автоматический перезапуск терминалов
- Закрыть все Fish терминалы
- Открыть их заново
- ❌ Теряется история и контекст

### Вариант 2: Указать в Fish конфиге автообновление
```fish
# В ~/.config/fish/config.fish
function check_config_update --on-event fish_prompt
    # Проверять изменения конфига при каждом промпте
    if test ~/.config/fish/config.fish -nt /tmp/fish_config_timestamp
        source ~/.config/fish/config.fish
        touch /tmp/fish_config_timestamp
    end
end
```
- ✅ Автоматическое обновление
- ⚠️ Проверка при каждом промпте (может быть медленно)
- ⚠️ Требует модификации config.fish

### Вариант 3: Текущий (буфер обмена) ✅ **Рекомендуется**
- Простой и надежный
- Полный контроль
- Нет рисков

## 📝 Итог

**Это оптимальное решение** для Fish shell в рамках его архитектурных ограничений. Копирование в буфер обмена - это баланс между удобством и безопасностью.

1. Откройте новый терминал
2. Fish автоматически загрузит обновленный конфиг
3. Всё работает! 😊
