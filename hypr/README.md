# hypr — раскладка клавиш

Весь набор биндов живёт в `.config/hypr/bindings.lua`. Стоковые бинды Omarchy
выключены штатным флагом, поэтому в системе есть только то, что написано в этом
файле.

## Как это подключено

| что | где | в репо |
|---|---|---|
| все бинды | `~/.config/hypr/bindings.lua` | да (этот пакет) |
| флаг `omarchy_default_bindings = false` | `~/.config/hypr/hyprland.lua` | нет — файл принадлежит Omarchy, его переписывают миграции; флаг ставится шагом установки (корневой README) |
| пресеты ширины колонок | `~/.config/hypr/looknfeel.lua` | да |
| нижние виджеты | пакет `pypr` | да |

Если флаг на машине не выставлен, при входе придёт уведомление: иначе
стоковые бинды вернутся поверх наших и пересекутся.

Код Omarchy не копируется, где его можно подключить. Исключение — SUPER+C/V/X:
штатный модуль `default.hypr.bindings.clipboard` называет клавиши буквами
(`"V"`), а Hyprland ищет букву в активной раскладке — в русской её нет, и вставка
в браузер падает с `send_key_state: key not found`. Поэтому его логика
(Ctrl+Insert/Shift+Insert в терминал, Ctrl+C/V/X остальным) переписана в
`bindings.lua` с кодами клавиш (`code:55` = V), которые от раскладки не зависят.
Остальные команды — те же `omarchy-*` скрипты, что
в стоке, у каждого перенесённого бинда в комментарии `was:` — прежняя клавиша.

## Правило: один модификатор — один смысл

| модификатор | смысл | примеры |
|---|---|---|
| SUPER | навигация: куда смотреть | hjkl фокус, 1–0 стол, F клик с клавиатуры |
| SUPER + SHIFT | запуск: что открыть | Enter терминал, B браузер, T Telegram |
| SUPER + ALT | действие над окном | hjkl двигать, 1–0 унести на стол, Q закрыть, M fullscreen |
| SUPER + CTRL | состояние системы | панели бара, уведомления, нижние виджеты |
| SUPER + большой палец | меню и системные утилиты | Esc питание, Space меню, Enter скриншот |

Исключение одно: SUPER + C / V / X (копировать, вставить, вырезать) — слишком
частые, чтобы брать два модификатора.

Тройных модификаторов нет: на клавиатуре с home-row mods это три пальца одной
руки.

## Клавиатура

Hallie (Corne-подобная, 3×6+3), ZMK, репо `mr-scrpt/hallie-zmk-config`.
Модификаторы на домашнем ряду при удержании, на обеих половинах:
A/; = SUPER, S/L = ALT, D/K = CTRL, F/J = SHIFT.
Удержание большого пальца: SPACE → стрелки на hjkl, BACKSPACE → цифры.
PrintScreen есть только в слое, поэтому на PRINT ничего не висит.

## Как добавить бинд

1. Определи глагол: смотреть/идти — SUPER, открыть — SUPER+SHIFT, сделать с
   окном — SUPER+ALT, система — SUPER+CTRL.
2. Проверь, что клавиша свободна:
   `hyprctl binds -j | jq -r '.[] | "\(.modmask) \(.key) \(.description)"'`
   (modmask: SUPER 64, SHIFT 1, ALT 8, CTRL 4).
3. Добавь `o.bind(...)` в нужную секцию `bindings.lua`. Команду для стокового
   действия бери из `/usr/share/omarchy/default/hypr/bindings/*.lua`.
4. `hyprctl reload && hyprctl configerrors` — вывод должен быть пустым.
